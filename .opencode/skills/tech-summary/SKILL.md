# Tech Summary 深度分析技能

本技能负责读取采集阶段产出的原始数据（`knowledge/raw/`），
对每条技术内容进行深度分析——生成精炼摘要、提炼技术亮点、
给出 1–10 分评级并附带理由，同时识别本轮数据的整体趋势与新概念，
输出为标准 JSON，供整理 Agent / 分发渠道使用。

## 使用场景

- 每日采集完成后，对 `knowledge/raw/` 最新文件做深度分析
- 需要从一批项目/文章中提炼「技术亮点」与「值得跟进的点」
- 需要给出统一口径的质量评分，便于后续去重与分发排序
- 用户询问「这批项目哪些值得关注、有什么趋势」时

## 执行步骤

### 1. 读取最新采集文件

- 使用 Glob 扫描 `knowledge/raw/` 目录，定位最新一批采集文件
  （如 `github-trending-YYYY-MM-DD.json`、`hacker-news-YYYY-MM-DD.json`）
- 使用 Read 读取对应 JSON，解析出待分析的 `items`
- 同一批次可包含多个来源文件，逐个解析后合并分析

> 若 `knowledge/raw/` 为空或文件损坏，记录原因并返回空结果，不得编造内容。

### 2. 逐条深度分析

对每个 item 产出以下四项分析：

| 分析项     | 要求                                                                 |
|------------|----------------------------------------------------------------------|
| 摘要       | 中文，**≤ 50 字**，一句话讲清「是什么 / 解决什么问题」              |
| 技术亮点   | 2–3 条，**用事实说话**（引用具体特性、性能数字、架构决策，避免空话） |
| 评分       | 1–10 整数，**必须附评分理由**（一两句话说明为什么给这个分）         |
| 标签建议   | 1–5 个，覆盖领域 / 技术栈 / 适用场景                                 |

**评分标准**（严格遵守）：

| 分数段 | 含义                                   | 典型特征                                  |
|--------|----------------------------------------|-------------------------------------------|
| 9–10   | 改变格局（game-changer）               | 开新方向、显著优于现有方案、有里程碑意义  |
| 7–8    | 直接有帮助                             | 成熟可用、能立即落地、解决明确痛点        |
| 5–6    | 值得了解                               | 有参考价值但尚不成熟 / 适用面有限         |
| 1–4    | 可略过                                 | 同质化、信息量低、领域不相关              |

> ⚠️ **评分约束**：一批 15 个项目中，**9–10 分合计不超过 2 个**。
> 高分必须对应真正改变格局的成果，宁缺毋滥；超出上限时回退到 8 分并说明原因。

必要时使用 WebFetch 查阅项目 README / 发布说明，补充分析依据（只读，不写入）。

### 3. 趋势发现

在逐条分析完成后，跨条目做横向归纳：

- **共同主题**：多个项目共同指向的方向（如「多 Agent 协作」「本地小模型推理」「RAG 检索优化」）
- **新概念**：本轮首次出现、值得记录的新术语 / 新方法 / 新范式

要求基于实际数据归纳，不得生造趋势；条目过少时可省略对应字段。

### 4. 输出分析结果 JSON

将逐条分析 + 趋势发现组装为标准 JSON，目标写入路径：

```
knowledge/articles/tech-summary-YYYY-MM-DD.json
```

> ⚠️ 本技能的 `allowed-tools` 不含 Write，实际落盘由调用方（如分析 Agent / 编排器）完成；
> 本技能负责产出符合以下结构的内容。

## 注意事项

- ✅ **只读不写**：本技能仅使用 Read/Grep/Glob/WebFetch，不修改任何文件
- ✅ **客观评分**：评分必须基于事实，禁止因「名气大」就给高分；9–10 分有严格上限（≤2/15）
- ✅ **事实说话**：技术亮点引用具体特性 / 数字 / 架构，杜绝「非常强大」「极其优秀」类空话
- ✅ **摘要精炼**：单条摘要 ≤ 50 字，超出即精简
- ✅ **理由必备**：每个评分都必须附带可读的理由
- ✅ **真实趋势**：趋势与新概念须从实际条目归纳，不得编造
- ✅ **中文优先**：摘要、亮点、理由统一用中文；项目名、URL 等保留原文

## 输出格式

```json
{
  "source": "github_trending",
  "skill": "tech-summary",
  "analyzed_at": "2026-06-21T01:00:00+08:00",
  "items": [
    {
      "name": "langchain-ai/langgraph",
      "url": "https://github.com/langchain-ai/langgraph",
      "summary": "图式 Agent 编排框架，支持有状态多步推理与流式 checkpoint。",
      "highlights": [
        "引入 subgraph 持久化，支持复杂多 Agent 拓扑",
        "流式 checkpoint 使长任务可中断恢复",
        "原生集成 LangChain 生态，工具调用开箱即用"
      ],
      "score": 8,
      "score_reason": "生产可用、解决多 Agent 编排痛点，但同赛道竞品较多，尚未形成压倒性优势。",
      "tags": ["agent", "workflow", "langchain", "orchestration"]
    }
  ],
  "trends": {
    "common_themes": [
      "多 Agent 协作与任务编排",
      "本地 / 边缘小模型推理优化"
    ],
    "new_concepts": [
      "subgraph checkpoint：子图级状态持久化与恢复"
    ]
  }
}
```

### 字段说明

| 字段            | 位置   | 类型       | 说明                                          |
|-----------------|--------|------------|-----------------------------------------------|
| `source`        | 顶层   | `string`   | 被分析数据的来源（如 `github_trending`）       |
| `skill`         | 顶层   | `string`   | 固定值 `tech-summary`（产出本数据的技能名）   |
| `analyzed_at`   | 顶层   | `string`   | 分析完成时间，ISO 8601（北京时间）            |
| `items`         | 顶层   | `array`    | 逐条分析结果                                  |
| `name`          | item   | `string`   | 项目 / 文章标识                               |
| `url`           | item   | `string`   | 原文链接                                      |
| `summary`       | item   | `string`   | 中文摘要（≤ 50 字）                           |
| `highlights`    | item   | `string[]` | 技术亮点（2–3 条，事实驱动）                  |
| `score`         | item   | `number`   | 评分 1–10（一批中 9–10 分 ≤ 2 个）           |
| `score_reason`  | item   | `string`   | 评分理由                                      |
| `tags`          | item   | `string[]` | 标签建议（1–5 个）                            |
| `trends`        | 顶层   | `object`   | 趋势发现（条目过少可省略）                    |
| `common_themes` | trends | `string[]` | 共同主题                                      |
| `new_concepts`  | trends | `string[]` | 新概念 / 新术语                               |
